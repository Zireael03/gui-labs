Реализован графический интерфейс конвертера веса на языке Python с использованием библиотеки PyQt5 и механизма сигналов и слотов. При изменении значения в одном из полей ввода (килограммы, граммы или фунты) автоматически пересчитываются и обновляются значения в остальных полях. Логика обработки сигналов разделена по отдельным модулям.
